# Full-Stack Dealership Capstone

## Repository Name
fullstack-dealership-capstone

## Project Name
Dealership Web Application

## Project Description
A full-stack web application for a car dealership retailer. The application will allow users to browse dealership locations, view dealer details, register and log in, and submit dealership reviews.

## Technologies
- Frontend: React, HTML, CSS, JavaScript
- Backend: Django and Django REST Framework
- Database: SQLite
- API Testing: cURL
- Version Control: Git and GitHub

## Project Objectives
- Display dealership information and locations.
- Support user registration, login, and logout.
- Allow users to view and submit dealer reviews.
- Integrate review sentiment analysis.
- Practice CI/CD and cloud deployment.

## Project Status
Initial project setup. Features will be added and tested as development progresses.
